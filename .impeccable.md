# Design Context — Grow Local Visibility (marketing site, client-site/)

## Target audience
Owner-operators of local service businesses: auto repair shops, plumbers,
painters, electricians, tire shops, handymen. Mostly 35-65, phone-first,
non-technical, busy (under a car / on a roof all day), skeptical of marketers
and of anything that smells like an agency retainer. Many have been burned by
"SEO guys" before. They evaluate on: does this person seem honest, is there
risk, will this get my phone ringing.

## Use cases / jobs to be done
- "I know I need a website but I don't have time or skills" → see that we
  build it FOR them, free, before any payment
- "Is this a scam?" → risk reversal everywhere: no card, see it first, own it
- "Will this actually get me customers?" → concrete proof: Google/Maps stats,
  missed-call math, real site examples
- Primary conversion: fill the short contact form (or reply to our outreach)

## Brand personality / tone
Plain-spoken tradesman trust. Sounds like a competent contractor quoting a
job: direct, concrete, no jargon, no hype. Confident but never salesy.
"We do the work. You get the customers." Green = growth/go; white = clean,
honest, nothing hidden. NOT: startup-y, gradient-y, buzzwordy, dark-mode tech.

## Constraints
- Next.js static export + Tailwind v4 tokens in client-site/app/globals.css
  (--background #ffffff, --foreground, --green #16a34a, --surface, --border,
  --muted). White/light theme is a hard requirement (Ryan's explicit choice).
- Single-page marketing site; form is client-side demo posting nowhere yet.
- NO fabricated testimonials, logos, or review counts. Real defensible claims
  only (e.g. 150+ sites built — CRM-verifiable).
- Offer ladder (authoritative in agents/shared/pricing.md): Free website /
  $99mo Managed / $199mo Growth (AI receptionist; fulfillment pending) /
  $500 one-time buyout.

Zero risk, zero effort. That inversion ("see it first") is the memorable thing.
